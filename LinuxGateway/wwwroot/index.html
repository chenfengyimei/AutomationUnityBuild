Topology

调度说明

LinuxGateway 只保存节点、用户和调度记录。项目配置、Unity/Xcode/Android 构建能力仍由各 BuildServer 节点维护。

Operations

推荐流程

  1. 在设备节点页维护 Mac/Windows BuildServer。
  2. 确认节点在线且项目/配置已同步。
  3. 到发起打包页提交任务，并在任务队列查看日志和产物。

常见地址填写

LinuxGateway 和 frps 在同一台服务器时，节点地址优先填 http://127.0.0.1:8090，不要填服务器公网 IP 回连自己。

Node Settings

新增 / 更新设备

填 LinuxGateway 能访问到的节点地址。若节点是同一台 Linux 上的 frps 端口，通常填 http://127.0.0.1:8090。

填节点 BuildServer 控制台打印的 Gateway Token。Token 错通常返回 401；连接超时通常是地址或网络问题。

Build Dispatch

发起打包

提交任务后会转发到选中节点执行。节点拉 Git、Unity 导出和 Xcode/Android 构建都可能需要几分钟。

Readiness

提交前检查

  • 目标设备必须在线并已同步远程项目。
  • iOS 任务建议选择 Mac 节点，Android 可选择 Mac 或 Windows 节点。
  • 首次提交建议保留 dry-run，确认 Git、Unity 和签名配置无误。
