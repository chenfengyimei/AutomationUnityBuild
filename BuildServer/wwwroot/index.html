系统怎么用

推荐流程

  1. 在 Mac 或 Windows 的本地 BuildServer 里维护项目和配置。
  2. 新增项目时填写 Git 仓库、工作区、产物目录和默认平台。
  3. 新增配置时选择 iOS 或 Android，勾选“生成新的配置文件”。
  4. 配置保存后，到“打包任务”选择项目和配置，先用演练模式（dry-run），再正式打包。
  5. 如果使用 LinuxGateway，它只负责选择设备和发任务，具体配置仍在本机 BuildServer 维护。

项目字段

Git 仓库
填写可 clone 的地址，例如 git@github.com:org/game.git 或 https://github.com/org/game.git。
允许分支
限制可打包分支，例如 main、release/*。多个用逗号隔开。
Workspace Root
打包机本地拉代码目录。支持 ~ 表示用户主目录，例如 ~/UnityBuildWorkspace；也可填绝对路径如 /Users/buildbot/workspace。
Artifacts Root
打包产物和日志输出根目录。同样支持 ~ 或绝对路径，例如 ~/UnityBuildArtifacts。

Unity 和通用版本

Unity 工程相对路径
相对于仓库根目录的路径。仓库根目录就是 Unity 工程时填 .；如果 Unity 工程在子目录则填如 Client。必须能看到 Assets 和 ProjectSettings。
Unity 版本 / 完整路径
版本号如 2022.3.62f2c1，Hub 默认安装可只填版本号自动推导。特殊安装位置需填 Unity 可执行文件的绝对路径，如 /Applications/Unity/Hub/2022.3.62f2c1/Unity.exe。
Bundle Identifier
应用包名，例如 com.company.game。iOS 和 Android 都会用到。
Build Number 自动 +1
建议开启。正式打包会自动递增构建号，演练模式（dry-run）不递增。

iOS 字段

Apple Team ID
10 位 Apple Developer Team ID，不是公司名。
Deployment Target
最低 iOS 版本，例如 13.0。
Export Method
development 开发测试，ad-hoc 测试分发，app-store 提交 App Store。
允许 Xcode 自动处理签名
使用自动签名时建议开启；证书和描述文件必须在 Mac 当前用户的 Keychain / Xcode 里配置好。
上传 App Store Connect/TestFlight
开启后必须使用 app-store 导出方式，并填写 App Store Connect API Key 的 .p8 路径（绝对路径，支持 ~，如 ~/Secrets/AuthKey_XXXXXXXXXX.p8）、Key ID 和 Issuer ID。上传成功后构建会进入 TestFlight 处理队列。

Android 字段

Android Build Format
apk 只出 APK，aab 只出 AAB，both 两个都出。Google Play 通常用 AAB。
Android 输出目录 / APK / AAB 路径
不特殊指定时留空，工具会自动放到本次产物目录。
Min SDK / Target SDK
不确定可留空，使用 Unity 项目设置；强制指定时填整数，例如 23、35。
Keystore
正式 Android 包需要签名文件路径、Keystore 密码、Key Alias 和 Alias 密码。路径必须是打包机本地绝对路径，支持 ~，如 ~/Secrets/game.keystore。

TikTok 小游戏字段

TikTok App ID
在 TikTok 开放平台创建小游戏后获取的 App ID。
Access Token
TikTok 开放平台的访问令牌，用于 API 上传鉴权。敏感信息，请妥善保管。
游戏名称
TikTok 后台显示的游戏名称，上传时用于标识。
WebGL 输出目录
Unity WebGL 构建产物输出目录。留空时自动放到本次产物目录下的 TiktokWebGL 文件夹。
API 端点
TikTok 开放平台 API 地址，默认 https://open-api.tiktokglobalshop.com，一般不需要修改。
上传 TikTok 小游戏
勾选后，打包完成会自动将 WebGL 产物打包为 ZIP 并上传到 TikTok 开放平台。需要先填写 App ID 和 Access Token。

Google Play 上传

上传 Google Play
只有要自动上传到 Google Play Console 时才勾选。
Google Play Package
一般等于 Bundle Identifier，例如 com.company.game。
Service Account JSON
Google Play 服务账号 JSON 文件的绝对路径，支持 ~，如 ~/Secrets/google-play.json。是打包机本地文件。
测试轨道 / 发布状态
建议先用 internal + draft，确认流程无误后再改正式发布策略。
灰度比例
灰度比例，填 0.1 到 1；内部测试或草稿通常留空。

LinuxGateway 设备填写

BuildServer 地址
填 Mac/Windows 本地 BuildServer 的外部可访问地址，例如 http://<your-buildserver-ip>:8090。
Gateway Token
填该设备启动 BuildServer 时控制台打印的 Gateway Token。未手动设置 BUILD_SERVER_GATEWAY_TOKEN 时，服务会自动生成并保存到 initial-gateway-token.txt。
平台勾选
Mac 通常勾 iOS 和 Android；Windows 通常只勾 Android。

常见排查

先用演练模式
新增项目或配置后，先用演练模式（dry-run）看路径、Git、Unity 和 Xcode/Android 参数是否正确。
看日志
失败时优先看任务详情里的完整日志，再看本次产物目录下的 Unity、Xcode 或 Android 日志。
路径归属
配置里的路径属于实际执行打包的 Mac/Windows，不属于 LinuxGateway。相对路径（如 .、Client）相对于仓库根目录；支持 ~ 的路径（如 ~/Secrets/）展开为用户主目录；其余路径需填绝对路径。

CLI 打包工具
